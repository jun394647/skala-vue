# 농사 날씨 (`MODE = 'farm'`)

과제 실습을 바탕으로 만든 개인 프로젝트입니다. 지역별 날씨가 아니라, **농가가 실제로 키우는 작물별로 오늘 날씨가 위험한지**를 알려주는 대시보드입니다. 채점 대상이 아니고, 화면도 완전히 다릅니다(전체 화면 다크 글래스 UI, 밭/흙 배경).

## 컨셉

경기 이천(`Icheon-si,KR`) 고정 위치 기준으로 날씨를 가져와서, 등록된 작물마다 안전/주의/위험을 판정합니다. "몇 도, 몇 %"가 아니라 "오늘 고추는 괜찮고, 배추는 서리 조심하세요" 처럼 작물 단위로 바꿔서 보여주는 게 핵심입니다.

## 기본 작물 목록

| 작물 | id |
|---|---|
| 벼 | `rice` |
| 배추·무 | `leafy` |
| 사과·배 | `orchard` |
| 고추 | `pepper` |
| 감자·고구마 | `root` |
| 감(곶감) | `persimmon` |

우측 상단 설정에서 실제로 키우는 작물만 골라 표시할 수 있고(`CropSettings.vue`), 선택은 `localStorage`에 저장됩니다.

## 화면 구성

- **메인 작물 히어로 카드**: 선택 작물 중 가장 위험도가 높은 작물을 SVG 일러스트로 표시 — 작물 종류(벼/로제트형 잎채소/과수/고추/뿌리채소/감나무)마다 다른 모양, 날씨 상태(맑음/흐림/비 등)에 따라 잎이 시들거나 생기 있게 변함
- **작물별 위험도 카드**: 등록 작물 전체를 안전(safe)/주의(caution)/위험(danger)로 정렬 표시
- **오늘의 작업 추천 시간대**: 일출·일몰과 예상 일조시간을 계산해 "지금이 작업하기 좋은 시간"을 안내
- **서리 예보**: 최저기온 기준 서리 위험 경고
- **대기질(AQI)**: OpenWeatherMap 대기오염 API 기반 등급 표시
- **글씨 크게 모드**: 고령 농업인을 고려한 접근성 토글 (`localStorage` 영속)
- **배경**: 날씨 무드에 따라 바뀌는 다크 그라디언트 + 밭(흙) 톤 배경

## 사용 API

OpenWeatherMap 3종 — 현재 날씨(`/weather`), 예보(`/forecast`), 대기질(`/air_pollution`). `VITE_OPENWEATHER_API_KEY` 필요(과제 화면과 키 공유).

## 실행

```js
// src/App.vue
const MODE = 'farm'
```

로컬 확인용이며 별도로 배포하지는 않았습니다(현재 배포는 `exercise` 모드 기준).
